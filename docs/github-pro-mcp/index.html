Why this server

Built for real work, not demos.

Most GitHub MCP servers expose a thin wrapper around a handful of endpoints. This one covers the work your agent needs to finish.

Issues and pull requests

Read, comment, label, review and merge. The agent can carry the whole review loop without a second tool.

Files and code

Read, create, update and delete files, and search code across repositories.

Projects and fields

Set Priority and Effort, and move items through Projects v2 without leaving the conversation.

Organizations and repositories

Find repositories, search code and list organizations, so the agent knows where it is working.
