Why this server

Built for real work, not demos.

Most GitHub MCP servers expose a thin wrapper around a handful of endpoints. This one covers the full workflow, and handles the failure modes that show up in practice.

Hybrid REST and GraphQL

REST for CRUD and search, GraphQL for cursor pagination and composite reads. One server, the right API for each job.

Resilient by default

Automatic retries with exponential backoff and jitter, a circuit breaker for outages, and proactive rate-limit handling.

Safety guardrails

Pin the server to one owner or repository so an agent cannot reach beyond the scope you intended.

Readable logs

Multi-level stderr logging, from errors to debug traces, so a failing tool call is easy to diagnose.
