Install

Install GitHub Pro MCP

The server runs locally and talks to the GitHub API with a personal access token you create. Install it with npm or Docker, then point your MCP host at it.

1. Create a token

Use the token generator to build a pre-filled GitHub page with the right permissions. It only constructs the URL; the token is created on GitHub.

Create a token

2. Install the server

npm

npm
1
npm install -g github-pro-mcp

Docker

docker
1
docker pull anantanandgupta/github-pro-mcp

Cursor and VS Code

Add the same server block to the host's MCP settings. Use the npx command for a zero-install setup, or point it at the global binary.

Environment variables

Variable Required Description
GITHUB_PERSONAL_ACCESS_TOKEN Yes Fine-grained or classic token with the permissions you need.
GITHUB_OWNER No Pin the server to one owner and reject mismatched calls.
GITHUB_REPO No Pin the server to one repository.
GITHUB_HOST No GitHub Enterprise Server API URL.
