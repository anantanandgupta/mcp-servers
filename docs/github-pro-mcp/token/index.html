After creating the token

  1. Store it in a gitignored file at the project root, for example .secrets/github_pro_token. Confirm .secrets/ is in .gitignore before you paste the token.
  2. Restrict the file with chmod 600.
  3. Set GITHUB_PERSONAL_ACCESS_TOKEN in your MCP host, or reference the file if your host supports file interpolation, then restart the host.
  4. Verify with auth_get_current_login.
