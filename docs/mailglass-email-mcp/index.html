Why this server

Reading mail, and nothing else.

Most email MCP servers hand the agent a full mailbox editor. MailGlass does not have that capability to give.

Read-only by design

Mailboxes are opened with EXAMINE and bodies fetched with BODY.PEEK. There is no send, move, delete or mark-as-read path in the code.

Two providers, one interface

Gmail for its query language and native threads; any IMAP server for everything else. The same eight tools work on both.

Capabilities you can ask for

server_info reports what each account can actually do, so the agent knows before it calls a tool that IMAP threads are reconstructed, not native.

Nothing leaves your machine

No servers, no telemetry. An optional local cache keeps repeat reads instant, and you can switch all disk writes off.
