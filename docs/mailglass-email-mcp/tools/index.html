Tools

Eight tools. All read-only.

Every tool only inspects mail. There is no send, move, delete, label or mark-as-read capability to enable; the gate defaults to read-only and the code has no write path.

Search filters

The same filter shape works on both providers, but each one fills in as much as it can. Where a filter cannot be honoured, the server explains that instead of guessing.

FilterGmailGeneric IMAP
fromsubject Full Full
unread Full Full
keyword Full, full syntax: from, label, larger, OR Partial, literal text only
has_attachment Full Not supported, refused with an explanation
afterbefore Full, Gmail date semantics Partial, arrival date, not the Date header
folderlimitcursor Full Full

Attachments and images

get_attachment writes to disk and returns a path by default. Pass inline: true to receive an image as an image block; opt-in, because images cost vision tokens and their contents are untrusted input. Anything above ~4 MB still returns a file.
